## Interpretation
- vf_lightup 预设（U-Net256 + VF-guided Retinex light-up branch）在整体指标上与 improve 预设（vf_blend+vf_attention）几乎一致
- RepairGain/VF-RI 略低 0.016，说明 light-up branch 在修复力度上略弱于纯 vf_blend 路线
- 但 light-up 保护正常区能力很好（NormalPenalty 0.033），过曝压制极佳（OverPenalty 4.4e-6）
- 轻中度损伤区 PSNR 高（28.52 / 27.82），SSIM 优秀（0.971 / 0.959）
- 重度区指标合理（SSIM 0.914，LPIPS 0.078），有提升空间

## OpenClaw Advice
